# LIBRARY MANAGEMENT SYSTEM

## Project Description

The Library Management System is a console-based C++ application developed to manage books, members, and borrowing records efficiently.

The project uses Object-Oriented Programming and file handling to manage library operations.

## Key Features

- Add new books
- Display all books
- Add library members
- Display all members
- Issue books
- Return books
- Search books by title
- Search books by author
- Store book data using file handling
- Store member data using file handling

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- Dev-C++

## Classes Used

### Book Class

Stores:
- Book ID
- Book title
- Author name
- Book status

### Member Class

Stores:
- Member ID
- Member name

### Library Class

Handles:
- Book management
- Member management
- Book issue
- Book return
- Search operations
- File handling

## How to Run

1. Download or clone this repository.
2. Open `library_management.cpp` in Dev-C++.
3. Compile the program.
4. Run the program.
5. Select an option from the menu.

## Expected Outcome

A functional application that enables book addition, issue and return processing, member management, and search by title or author.
